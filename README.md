# Python - Manipular Arquivo CSV com Pandas

Este projeto demonstra como manipular arquivos CSV em Python utilizando a biblioteca `pandas`. O objetivo é ler, processar e exibir dados estruturados de forma eficiente, facilitando a análise e manipulação de informações.

---

## 📌 Funcionalidades Principais

- **Leitura de arquivos CSV**: Importação de dados de um arquivo CSV com configurações personalizadas (delimitador, cabeçalho, nomes de colunas).
- **Processamento de dados**: Utilização da biblioteca `pandas` para manipular e formatar os dados.
- **Exibição amigável**: Iteração sobre os dados e exibição formatada para melhor visualização.

---

## 📂 Arquivos do Projeto

| Arquivo      | Descrição                                                                 |
|--------------|---------------------------------------------------------------------------|
| `data.csv`   | Armazena dados estruturados em formato CSV para manipulação e análise.    |
| `main.py`    | Script Python para leitura, processamento e exibição de dados do arquivo CSV utilizando `pandas`. |

---

## 🚀 Como Executar o Projeto

### Pré-requisitos
- Python 3.x instalado.
- Biblioteca `pandas` instalada.

### Passos para Execução
1. Clone o repositório ou baixe os arquivos `data.csv` e `main.py`.
2. Instale a biblioteca `pandas` utilizando o seguinte comando:
   ```bash
   pip install pandas
   ```
3. Execute o script `main.py`:
   ```bash
   python main.py
   ```
